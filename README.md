## About

The Call of Cthulhu Guide Website is a comprehensive reference resource for players and Keepers of both new and experienced levels. Whether you're creating an investigator, learning the game mechanics, or planning your next campaign, this guide provides quick access to essential rules, character creation guidelines, and keeper resources to enhance your gaming experience.

Demo: [Click me](https://caleblui52.github.io/COC-Guide-Website/)

## Project Structure

The repository is organized as follows:

```
COC-Guide-Website/
├── html/          # HTML markup and page templates
├── css/           # Stylesheets and responsive design
├── js/            # JavaScript functionality and interactivity
```

### Directory Descriptions

- **html/** - Contains all HTML files for the guide pages (investigator creation, rules, mechanics, etc.)
- **css/** - Styling files including responsive layouts for desktop, tablet, and mobile devices
- **js/** - JavaScript files for interactive features and dynamic content
- **resource/** - Static assets such as character sheets, artwork, and reference materials

## Getting Started

### Prerequisites

- A modern web browser
- No external dependencies required - this is a static website

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/caleblui52/COC-Guide-Website.git
   ```

2. Navigate to the project directory:
   ```bash
   cd COC-Guide-Website
   ```

3. Open the main HTML file in your browser or serve locally with a web server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Python 2
   python -m SimpleHTTPServer 8000
   ```

4. Open your browser and navigate to `http://localhost:8000`

## Usage

Open the website in your browser to explore the Call of Cthulhu reference guides. Use the navigation menu to access different sections including investigator creation rules, game mechanics, keeper resources, and scenario guides. The site is fully responsive and adapts to any device or screen size.
